# NEON RAID — Two Stage Build v0.5

Полная автономная HTML5-игра из двух этапов.

Этап 1:
- 8-direction Raider
- 8-direction Corp Sec
- две волны врагов
- укрытия, взрывающиеся бочки, аптечка
- AI: приближение, отход, стрейф, короткие очереди
- пули блокируются укрытиями

Этап 2:
- анимированный Warden-X из последнего sprite sheet
- движение босса
- 3 фазы
- веерные и радиальные атаки
- красные зоны
- дым при повреждении
- аптечки

Управление:
- WASD / стрелки
- Space — FIRE
- Shift — DASH
- G — граната
- мобильные кнопки работают касанием

Главный index.html автономный: все изображения встроены внутрь, поэтому его можно открыть двойным кликом без HTTP-сервера.
